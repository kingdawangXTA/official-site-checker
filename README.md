# 官方网站识别器

一个基于 Manifest V3 的浏览器插件，通过域名白名单、ICP 备案、HTTPS、跨域表单等多信号综合评分，判断当前网站是否为官方网站。

## 安装

1. 下载本项目 ZIP 并解压
2. 打开 `chrome://extensions`，开启「开发者模式」
3. 点击「加载已解压的扩展程序」，选择解压后的文件夹

## 识别逻辑

- 域名命中官方白名单 → 直接判定官方
- ICP 备案号 +30
- HTTPS +10 / 非 HTTPS -20
- 原始 IP 访问 -30
- 跨域登录表单 -30

总分 ≥40 疑似官方，≥10 无法确定，其余判为可疑。
